# 🎡 游乐园主题公园经营模拟（ThemePark Tycoon）

一款可浏览的在线网页版主题公园经营模拟游戏。作为游乐园总经理，你需要规划园区、建设游乐设施与商铺、管理员工、调整票价、举办活动并应对突发事件，把一座空地建成繁华的主题乐园。游戏内置时间模拟引擎，数值实时演算，具备完整的经济循环与成长曲线。

## 技术栈

- **前端**：Vue 3 + Vite + Pinia（状态管理）+ 内联 SVG 图表
- **后端**：Express + Node.js 内置 `node:sqlite`
- **数据库**：SQLite（`server/park.db`）
- **通信**：REST API，Vite 代理 `/api` 到后端
- **启动**：`concurrently` 同时拉起前后端

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 同时启动后端(4150) 与 前端 Vite
```

浏览器访问 Vite 输出的地址（默认 `http://localhost:5200`，若被占用会自动切换端口）。

## 数据模型（SQLite 表）

| 表 | 说明 |
|----|------|
| `zones` | 园区区域（主题 / 解锁状态 / 清洁度 / 容量） |
| `rides` | 游乐设施（类型 / 健康度 / 刺激度 / 票价 / 累计营收） |
| `vendors` | 商铺（餐饮 / 纪念品 / 饮品，定价与毛利率） |
| `staff` | 员工（保安 / 保洁 / 维修，工资与满意度） |
| `visitors` | 客流统计（每时段入园人数与满意度） |
| `finance` | 财务流水（逐条收支明细） |
| `events` | 活动及突发事件（影响声誉与客流） |
| `complaints` | 游客投诉工单（类别/严重度/状态/受理员工/进度/限时/升级/补偿/评价） |
| `complaint_logs` | 投诉处理时间线（提交/指派/升级/处置完成/补偿结案等） |
| `loans` | 分期贷款（本金 / 期数 / 每期利率 / 等额本息月供 / 剩余本金 / 逾期挂账） |
| `settings` | 经营全局参数（票价 / 现金 / 声誉 / 时间） |

## 核心玩法

- **时间模拟**：游戏每 2 秒推进 1 小时，自动结算门票、游乐、商铺收入，扣除运营成本、员工工资与租金，设施健康度随时间衰减。
- **经济循环**：票价影响入园量与单客收入的取舍；声誉由满意度、事件与财务状况驱动。
- **事件系统**：玩家可策划烟火 / 花车巡游等活动，同时会随机遭遇阵雨、设备故障、投诉潮、明星到访等突发事件，需要决策处置以免损伤声誉。
- **投诉与服务补救**：游客反馈随长队、卫生差、设施故障、排队投诉潮等状况自发产生，也可在「投诉补救」页面前台手动登记。投诉分一般/严重/紧急三级并有处置时限，指派岗位匹配的员工（保安/保洁/维修）推进处置进度；可手动升级或在超时时自动升级，紧急投诉仍超时将引发公开差评事件。现场处置完成后选择道歉/赠票/快速通行券/消费券/现金补偿结案，依据处置质量与补偿档次产生 1–5 星评价，回流声誉、员工满意度与服务口碑，口碑进一步影响后续客流与满意度；不予补偿结案则扣减声誉与口碑，补偿支出记入财务流水。
- **成长空间**：可扩建未解锁区域、升级设施刺激度、增聘员工提升清洁与服务。
- **分期贷款**：可自选借款金额、期数（游戏日）与每期利率（等额本息）。每日闭园日结时自动扣 1 期并同步记录本金/利息流水；现金不足则按「利息→本金」部分偿还，余额挂账转逾期（按日计 2% 罚息、扣减声誉），后续日结优先补扣，也可随时提前结清（豁免未到期利息）。
